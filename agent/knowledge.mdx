An agent knows nothing about your company until you tell it. Knowledge sources are the facts it answers from: what CDL class you hire, your home-time policy, which lanes you run, how an applicant's next step works.

## Add a source

Open the agent, pick **Knowledge**, and click **Add source**:

- **Add URL** reads one web page. Paste the address, click **Scrape**, check the text it pulled out, then click **Add to Knowledge**. It doesn't follow links, so add each page you need (your careers page and your benefits page are separate sources). Very long pages get cut off.
- **Upload files** takes PDF, DOCX, TXT, MD, HTML and CSV files up to 10 MB. Vocal pulls the text out and shows it before you add it.
- **Write text** is for anything you'd rather type or paste: give it a **Name** and the **Content**.

A source you add from an agent's Knowledge page is switched on for that agent straight away.

## Sources are shared, switches are per agent

Sources belong to the workspace, not to one agent. Each agent's **Knowledge sources** list shows every source with a switch, and a row says when a source is used by more than one agent. Your recruiting agent and your after-hours agent can share the same driver FAQ while only one of them gets the pay sheet.

**AI Agents** › **Knowledge** lists all of the workspace's sources in one place, where you can add, retry or delete them.

Each source shows a status while Vocal prepares it for search: **Pending**, **Indexing**, **Ready**, or **Failed**. Retry a failed one from **AI Agents** › **Knowledge**.

<Warning>
  The switches decide which sources an agent is given, but its knowledge search on a call can find anything in the workspace's knowledge, including sources switched off for it. Don't add anything you wouldn't want any of your agents to say out loud, like internal margins or a driver's personal details.
</Warning>

## What to add

Start from what people actually ask. For a recruiting line that usually means:

- Hiring requirements: license class, years of experience, endorsements
- Pay structure and home time, even if the answer is "a recruiter goes over pay on the next call"
- Where you're hiring and which lanes you run
- What happens after the call, and how soon

Leave out anything stale. An agent confidently quoting last month's sign-on bonus does more harm than one that says it'll have a recruiter follow up.

## Publishing and knowledge

Switching a source on or off for an agent is part of the draft, so it waits for **Publish**. The text inside a source isn't: calls use the current version of every source as soon as it changes. See [What Publish controls](/agent/behavior#what-publish-controls).

<Tip>
  Read the week's calls in [Inbox](/inbox). When the agent took a message for something a source could have answered, add that source and switch it on.
</Tip>
